# 本轮非部署验收记录

本轮按[开发计划](AI可执行开发计划.md)完成通用进销存及基础设施的非部署节点和本地验收汇总。Nacos与通用操作审计仍未实现，部署和完整 v1.0 发布验收尚未进行，不能将本记录当作生产上线确认。

## 已实现范围

- 进销存后端包含物料、客户、供应商与仓库主数据，采购/销售订单、分批收货和出库、库存余额及流水；禁止负库存。主数据编码、物料单位及订单创建后的明细遵循已确认的固定规则。
- 本地账号、RS256 认证、Redis 会话撤销、角色权限及按仓库的数据范围已经接通；初始管理员凭据通过环境变量提供。
- 独立 Gateway 提供路由、来源限制和 Redis 共享限流；Starter 提供 OpenAPI 与 Knife4j。
- RabbitMQ 与 Outbox 提供持久化发布、同聚合顺序、重试和死信恢复；Quartz 与 ShedLock 提供后台任务，死信重放任务以实际消费凭据判定成功。
- Gateway、Starter、任务及消息使用独立业务关联 ID 与标准追踪上下文；指标、日志和追踪的实际验证范围见[开发与迭代](development.md)。

## 验收证据

2026-11-02 在隔离的 MariaDB 11.8、Redis 8.2 和 RabbitMQ 4.3.6 测试资源上重新执行全工程单元及网关、Starter 集成任务，共 1093 项通过：317 项单元、10 项 Gateway 集成、766 项 Starter 集成，零失败、错误或跳过。命令为 `./gradlew.bat --no-daemon test :stratum-gateway:integrationTest :stratum-starter:integrationTest --rerun-tasks`。

F02.6 另有 3 项真实 Agent 进程测试通过，分别覆盖 Gateway 到 Starter、Quartz 任务及消息追踪；消息重放前置归档由测试构造，后续重放、发送和消费使用真实组件。静态文本检查未发现 Domain 框架导入、Application/Query/Interface 对 Infrastructure 实现的直接导入、Infrastructure HTTP 端点或 Query 写入语句。各节点详细记录见[当前状态](CONTEXT.md)。

## 已知边界

- 当前仓库交付后端 API 和独立网关，未包含 ERP 前端；财务记账、税务、批次序列号、生产 BOM、审批、退货和反向冲销不在已确认首期范围。
- Nacos 尚未接入，配置通过环境变量提供；Nacos 动态刷新尚未验证。
- ERP 领域事件已持久化留痕，但通用业务操作审计和数据变更审计表尚未实现，不能将事件留痕当作完整操作审计。
- 死信采集多实例及关闭一个采集实例后的继续执行已验证；持有者进程强制故障接管未单独验证。
- D04.2、F03、F04.2 的部署、Compose、外部观测服务、多副本部署故障切换及回滚演练按用户要求暂缓；本轮没有进行部署或生产数据回滚。
