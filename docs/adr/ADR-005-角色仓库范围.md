# ADR-005：角色仓库范围

## 状态
已接受（用户于2026-10-25确认）。

## 背景
ADR-003已确定主数据共享、订单和库存按仓库授权，仓库范围的分配与合并规则需要落实。

## 决策
仓库范围配置在角色上，多角色取并集。administrator固定拥有全部仓库；普通角色默认没有可访问仓库，管理员可将其配置为全部仓库或精确指定集合。范围变更立即生效，不把范围结论写入JWT或缓存。

主数据共享仍要求相应API权限；订单及库存必须同时满足API权限和仓库范围。空指定集合表示无仓库访问权。组织、部门及本人归属保持未接入状态。

## 权衡与影响
复用已有角色成员关系，配置变化无需逐账号改写。仓库范围使用独立配置版本，与角色名称和API权限分别处理并发；写入仍由当前管理员在Application工作单元中执行，只读及目标范围检查经QueryGateway。读取过滤和写入目标校验均需覆盖，幂等重放不能绕过范围检查。此决定不代表数据过滤已实现，不包含部署。

## 关联规范
