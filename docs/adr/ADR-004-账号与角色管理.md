# ADR-004：账号与角色管理

## 状态
已接受（用户于2026-10-24确认）。

## 背景
本地账号、会话及RBAC关系读取已有基础，管理操作、初始授权和管理员保护需要明确规则。

## 决策
初始化管理员通过管理员角色拥有全部已登记权限，不凭初始化标记或JWT声明绕过权限检查。管理员可创建普通账号、启停账号、配置角色和分配权限；普通账号默认无业务权限。权限变更后立即生效，禁止停用或移除最后一个可用管理员。

## 权衡与影响
通过同一角色关系进行初始授权与后续管理，减少特殊身份分支。保护最后一个管理员需要覆盖并发变更，授权不得使用过期缓存。账号禁用须遵守既有撤销版本规则，并在认证及刷新入口拒绝禁用账号。管理写入由Application工作单元驱动，只读展示继续经QueryGateway；权限与仓库范围分开验证。此决策确认产品范围，不代表管理能力已交付，也不包含部署。

## 关联规范
SPEC-004、SPEC-005、SPEC-006、SPEC-007；对应D02.2d及D02.3。
