# ADR-003：本地账号与仓库数据权限

## 状态
已接受（用户于2026-10-24确认）。

## 背景
JWT签名与会话机制已确定，但账号来源未定义；ERP具有仓库维度，尚无公司、部门或员工归属模型。

## 决策
首期采用本地用户名/密码账号，以环境变量提供初始管理员账号与密码；无默认密码，不在仓库保存凭据。密码依F-016使用BCrypt存储。

主数据全局共享，订单和库存按仓库授权，支持全部仓库或指定仓库。读查询附加范围过滤，写操作验证目标仓库；全局共享不免除API权限校验。ORG、DEPT、SELF及其扩展范围保留通用契约，业务归属明确后再接入。

## 权衡与影响
本地账号无需接入外部身份提供方，初始化与凭据生命周期由应用维护。仓库授权对应现有业务维度，避免凭空推断组织和员工归属；以后引入组织模型时需要新增明确的业务映射。本决策不代表认证或授权已实现，也不包含部署。

## 关联规范
SPEC-004、SPEC-005、SPEC-006、SPEC-007；对应D01、D02和D03。
