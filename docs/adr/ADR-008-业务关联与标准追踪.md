# ADR-008：业务关联与标准追踪

## 状态

已接受，用户于2026-10-28确认；本决策不代表追踪或跨消息传递已经实现。

## 背景

现有 `X-Trace-Id` 是允许非十六进制值的业务关联标识，已用于响应、数据库事件、任务及日志。W3C Trace Context 的trace ID和span ID具有固定格式和跨度语义，不能将任意现有业务关联值当作标准追踪标识。

## 决策

保留现有业务关联ID及其兼容契约，同时使用独立的W3C trace ID与span ID；日志同时记录业务关联值与标准追踪值。标准追踪上下文按既有OpenTelemetry Java Agent与W3C规范接入；跨消息异步边界需要持久化并传播标准上下文，按后续节点实施。无有效标准跨度时不得伪造标准标识，也不能将仅透传的头称为端到端追踪完成。

## 权衡与影响

保留现有协议避免破坏接口、任务和事件身份；额外保存两套标识增加存储与诊断字段。关联值和标准跨度的生命周期可能不同，排障时需要明确区分。指标标签保持低基数，不将任一标识作为标签。
