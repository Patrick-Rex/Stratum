# 文档维护指引

- 保留现有专题文档及 SPEC / NODE 标识，避免使计划、提示词和历史记录失去引用目标。

- 修改入口、路径、状态或规范优先级时，同步检查上级 README、Copilot 入口和共享提示词。规范优先级以 [CONSTITUTION](CONSTITUTION.md) 第 1 节为准。
